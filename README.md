title: Constructing Brain Subnetworks via a High-Dimensional Multi-Task Learning Model with Group-wise Mixtures (HDMTGM).

The folder "reproducibility_materials" contains:
1. The R codes to conduct simulations via implementing HDMTGM, which replicate simulation results.
2. The R codes for real data analysis.
3. Some demo datasets (to be downloaded from the GitHub repository below) that are synthesize to illustrate the workflow because the UKB and HCP data are not allowed to share. Due to the large size of the synthetic datasets, we cannot include them in the submitted "reproducibility_materials" package. Readers are expected to create a sub-folder "reproducibility_materials/demo_datasets/", download the datasets in this GitHub repository, https://github.com/YY634/multi-task-learning-with-group-wise-mixture-parameters/tree/main/demo_datasets, and store the downloaded files under "reproducibility_materials/demo_datasets/".


Before running the R scripts or knit the Worklow.Rmd file, please set folder "reproducibility_materials" as the working directory. Under the working directory  ("reproducibility_materials"), there should be three sub-directories--"simulations",  "real_data_analysis", and "demo_datasets". 


The sub-directory "reproducibility_materials/simulations/" contains all the R scripts needed in Section 2.5 of the paper. The R script named "simulation_setting#.R" generates the results in Setting# of Section 2.5, where #=1/2/3/4/5/6. Note that the results of Setting 5 and 6 generated by the corresponding R scripts in this reproducibility package will be different from the ones in the paper. It is because we used real datasets from UKB and HCP-YA in Setting 5 and 6 of the paper, while the R scripts here takes synthetic datasets as input. 


The sub-directory "reproducibility_materials/real_data_analysis/" contains all the R scripts needed in Section 3. The purpose of each R script in this sub-directory has been explained in its header and in Workflow.Rmd and Workflow_realdata.txt. 
In the paper, we implemented the same workflow/procedure on each of the 22 autosomes. Analyzing all the 22 autosomes will take several days. For illustration purpose, the Workflow.Rmd will just go through the procedure for once on some synthetic datasets.  
Running these R scripts in a successive manner, “demo_ukb_chr18.R”, "demo_extract_cluster.R", "demo_cluster_yeo7_overlap.R", and "demo_visualizebrain_gene_clusters_multiplot.R", will produce several RData files containing desired results and a PDF file showing the visualization of one identified brain subnetworks. 
The results generated by this reproducibility package are different from the results in the paper because synthetic datasets are used here while real datasets from UKB and HCP-YA are used in the paper.
